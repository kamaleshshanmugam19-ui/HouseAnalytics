# Dataset source

`kc_house_data.csv` is the King County House Sales dataset distributed at [Kaggle](https://www.kaggle.com/datasets/harlfoxem/housesalesprediction). It contains residential sales recorded from May 2014 through May 2015. The API and Random Forest predictor use the dataset's sale price, living area, bedrooms, bathrooms, year built, lot size, ZIP code, grade, and sale date fields.

The dataset is included locally so the application does not need a runtime download. It is historical public data and is not a source of current listings or financial advice.
